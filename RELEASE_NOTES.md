# HT File Hash Checker 1.0.0 - release notes

**Status: release candidate, not yet published.** Publication as a stable release needs the signed advisory snapshot
and HTREASURE LTD approval (see *Before publication* below).

HT File Hash Checker is a Windows utility for calculating, comparing and verifying file checksums using SHA-256,
SHA-512, SHA-384, SHA-1 and MD5. Developed by HTREASURE LTD.

## Highlights

- Verify downloads by pasting the publisher's checksum: MATCH, MISMATCH or ERROR.
- Check whole folders against `SHA256SUMS` / `SHA512SUMS` / `MD5SUMS` manifests, and create your own.
- Handles very large files (ISO images over 4 GB) without loading them into memory; never modifies files.
- Batch processing with progress and cancellation; TXT, CSV and HTML reports.
- Optional "Calculate Hash with HT File Hash Checker" in the File Explorer right-click menu.
- Works offline. No account, subscription or telemetry.

## Supported Windows versions

Windows 7 SP1, 8.1, 10 and 11 (.NET Framework 4.8 build), and Windows 8.0 (.NET Framework 4.6.1 build); x86 and x64,
Arm64 through emulation. Tested on Windows 11 x64 only so far; see [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

## Installation

Run `HTFileHashChecker_Setup_v1.0.0.exe`. Choose all users (administrator) or only you (no administrator rights).
Setup installs .NET Framework from Microsoft only if it is missing and you agree. Details:
[docs/INSTALLATION.md](docs/INSTALLATION.md).

## Portable use

Unzip `HTFileHashChecker_Portable_v1.0.0.zip` and run `HTFileHashChecker.exe` (Windows 8.0: the copy in
`Windows 8.0 (NET 4.6.1)`). Settings stay in the `Data` folder next to the program; nothing is written to the registry
unless you turn on the Explorer menu yourself.

## Verifying the download

Compare each file's SHA-256 with `SHA256SUMS.txt`. Files are signed with HTREASURE LTD's self-signed certificate
(thumbprint `2F352812FE849999928F25F778A3D49AE5750EF2`); Windows may show "Unknown publisher" because the certificate is
not issued by a public certificate authority.

## Known limitations

- A matching checksum proves file equality with the expected value, not that a file is safe or authentic.
- MD5 and SHA-1 are legacy algorithms; MD5 may be unavailable where Windows enforces FIPS mode.
- Manifest entries with line breaks in names, non-UTF-8 names, tab-separated or absolute-path lines are rejected
  ([docs/MANIFEST_FORMATS.md](docs/MANIFEST_FORMATS.md)).
- The window has a fixed size (fitted to the screen) and no minimise button.
- The online advisory check and security-update check report "not configured": no HTREASURE advisory service or release
  feed exists yet. The bundled advisory history works offline.
- Self-signed code signature (see above). The product uses the corporate HTREASURE icon until a product icon is
  generated by the branding kit.
- Windows 7, 8, 8.1 and 10, x86, Arm64, all-users installation, the .NET download path and scaling above 100% have not
  yet been tested on real systems.
